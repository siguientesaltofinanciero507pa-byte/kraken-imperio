# 🐙 KRAKEN-SAPIENS V10.1 — Telegram Bot

Bot de ventas 24/7 de KRAKEN IMPERIO.

## Deploy en Railway

1. Conectar repo a Railway
2. Configurar variables de entorno:
   - `TELEGRAM_TOKEN` — Token de @BotFather
   - `ADMIN_ID` — Tu ID de Telegram
3. Deploy automático en cada push

## Comandos del Bot

- `/start` — Menú principal
- `/catalogo` — Ver servicios
- `/wallets` — Medios de pago
- `/health` — Estado del bot
- `/approve USER_ID` — Aprobar pago (admin)
